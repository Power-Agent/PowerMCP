Configuration and method
------------------------
Original library type: EvEMTBench Test Type 110-20, 20 MVA, 110/20 kV,
60 Hz, YNd11. Existing library type and integrated elements are not modified.
The script tests a separate temporary grid and type copy at each frequency:
60 Hz first, then 50 Hz only after a successful first run and cleanup.
Retained grid and type frnom: 60/60 and 50/50 respectively.
Run names: MCP YNd Ref 60Hz bd371340; MCP YNd Ref 50Hz 38a214d5.

Both cases hold input positive/zero-sequence per-unit impedances fixed at the
selected nominal frequency. They are not a physical frequency sweep of one
transformer. pfe=0 and curmg=0 on the temporary type remove the magnetizing
branch for this independent, unloaded sequence-network reference.

Reference equations and assumptions are those documented in FT-32:
Zbase=UHV^2/Sn=605 ohm; Ibase=Sn/(sqrt(3)*UHV).
Z1=Zsource1+Ztransformer1; Z2=Z1.
Z0=R0pu+jX0pu+3*(Rn+jXn)/Zbase, with source Z0 blocked by the delta.
I3ph=Ibase/abs(Z1); Iearth=3*Ibase/abs(Z1+Z2+Z0).
HV terminal I0=Iearth/3; LV terminal I0=0.
Both temporary-source cmax/cmin retained as 1.0. Prefault voltage checked
against 1.0 p.u. Complete Method code 3 is read from the inspected GUI template.
No solver fault current is used to fit an input or reference value.
