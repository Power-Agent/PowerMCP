Purpose and independent reference
---------------------------------
Compare PowerFactory Complete Method currents against a sequence-network
calculation using input impedances, not fitted solver fault-current results.
The temporary network is unloaded and has no magnetizing branch: pfe and
curmg are zeroed only on a temporary copy of the 20 MVA, 110/20 kV, 60 Hz
YNd11 source type. The existing source type and integrated transformer are
not modified. Neutral resistance is applied on the HV star side.

On transformer rated-power and HV-voltage bases:
  Zbase = UHV^2 / Sn = 605 ohm
  Ibase = Sn / (sqrt(3) * UHV) = 0.1049727762162956 kA
  abs(Zsource1) = Sn / Sk_source (source c-factor = 1)
  Xsource1 = abs(Zsource1) / sqrt(1 + (R/X)^2)
  Rsource1 = (R/X) * Xsource1
  Z1 = Zsource1 + R1pu + j*X1pu
  Z2 = Z1
  Z0 = R0pu + j*X0pu + 3*(Rn + j*Xn)/Zbase
  I3ph = Ibase / abs(Z1)
  Iearth = 3*Ibase / abs(Z1 + Z2 + Z0)
  I0_HV = Iearth/3; I0_LV = 0

The delta winding blocks source zero-sequence impedance from the HV fault
loop. Source negative-sequence impedance is configured equal to positive
sequence; transformer Z2=Z1 is an assumption of this reference model.
Source cmax and cmin are explicitly set to 1.0 on the temporary source.
An independent source-only check runs before the transformer comparisons.
Prefault HV voltage is checked against 1.0 p.u., not fitted to fault results.

Predeclared tolerances: relative 0.005 (0.5%); absolute 0.00001 kA.

Reproduction on the Lab PC
--------------------------
1. Save work and stop powerFactoryUnified. Launch interactive PowerFactory
   normally, without NON-INTERACTIVE MODE; activate test and Case 1.
2. Retain the inspected EvEMTBench Test Type 110-20 and the dedicated
   MCP Complete Method Template in Case 1, with complete selected (code 3).
3. Copy the archived script to a writable Lab PC working folder. Replace
   <user> in PROJECT with the actual PowerFactory account. Do not run this
   script against a production project or change the current tolerances.
4. Execute once through an external ComPython script object. The script
   checks the exact context, creates an isolated temporary case/network/type,
   runs controls and comparisons, then restores and cleans up.
5. Attach the uniquely named lab_results/YNd_reference_*.json beside the
   script. The Output Window contains a short summary, not the full JSON.
   The export opens its destination before running validation and never
   overwrites an earlier file. An export error is not a confirmed pass.
6. If success, restoration or cleanup fails, keep the full result and
   investigate; do not fit inputs or relax tolerances to obtain a pass.
