Catalog inspection:
list_evemtbench_load_profiles(voltage_kv=20) returned one profile from catalog
evemtbench-loads-table-5-v1. The 20 kV profile reported an apparent-power
range of 0.1 to 1.6 MVA and the power-factor limits 0.8 inductive to 0.95
capacitive. It identified ElmLod as the target class and plini and qlini as the
mapped constant-power attributes.

The response also disclosed the Table 5 ZIP-coefficient ranges as catalog-only
data. Those coefficients were not written because their PowerFactory attribute
mapping has not been live-validated.

- voltage_kv: 20
- load_name: MCP Bootstrap EvEMTBench Load 20
- bus_name: MCP Bootstrap MV 20
- grid_name: MCP Bootstrap Grid
- seed: 42
- out_of_service: true

The preview returned success=true, applied=false, and load_created=false. It
