Second-bus preview and creation:

MCP Bootstrap MV 20, with only MCP Bootstrap Cable End 20 pending. The preview
returned success=true, applied=false, grid_will_be_created=false,

The confirmed call returned success=true, applied=true, grid_created=false,

preview had correspondingly reported grid_will_be_activated=false.

Catalog inspection:
list_evemtbench_cable_profiles(profile="p50") returned the 20 kV entry from
catalog evemtbench-underground-cables-tables-3-6-v1. The catalog attributed
the voltage and length range to Table 3 and the electrical sequence values to
Table 6. Its p50 values were:
- r1: 0.2125 ohm/km
- x1: 0.1411 ohm/km
- c1: 247.06 nF/km
- r0: 0.7775 ohm/km
- x0: 0.2661 ohm/km
- c0: 247.06 nF/km

The response explicitly identified the implementation as a three-phase
underground-cable sequence equivalent. Construction and installation fields
remain catalog-only; the tool does not claim to reproduce the paper's
geometric ULM model. The caller supplied 0.4 kA because Table 6 does not
publish cable ampacity.
